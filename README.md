# E-commerce

Este é um projeto de E-commerce desenvolvido como parte de um estudo prático. Ele utiliza:

- **Back-end**: Node.js com Express
- **Banco de Dados**: PostgreSQL
- **Front-end**: React

## Funcionalidades

- Cadastro e autenticação de usuários
- Catálogo de produtos com filtros e categorias
- Carrinho de compras
- Processo de checkout e pagamento simulado
- Histórico de pedidos
- Área administrativa para gerenciamento de produtos e usuários

## Tecnologias Utilizadas

- **Back-end**:
  - Node.js
  - Express
  - Sequelize (ORM para PostgreSQL)
  - JWT (JSON Web Tokens) para autenticação

- **Front-end**:
  - React
  - React Router
  - Axios para requisições HTTP
  - Context API para gerenciamento de estado

- **Banco de Dados**:
  - PostgreSQL

## Como Rodar o Projeto

### 1. Clonar o Repositório

```bash
git clone https://github.com/anaalthoff/E-commerce.git
cd E-commerce
```

### 2. Instalar as Dependências
```bash
npm install
```
